# tmux 操作方法

## 基本設定

| 項目 | 値 |
|------|-----|
| プレフィックスキー | `Ctrl+t` |
| モード | vi モード |
| マウス | 有効 |

## ペイン操作

| キー | 操作 |
|------|------|
| `Alt+d` | 横分割（左右に分ける） |
| `Alt+D` | 縦分割（上下に分ける） |
| `Alt+h/j/k/l` | ペイン移動（左/下/上/右） |
| `Alt+H/J/K/L` | ペインサイズ変更 |
| `Alt+f` | ペインをズーム（最大化/元に戻す）(focus) |
| `Alt+q` | ペインを閉じる(quit) |
| `Alt+s` | 全ペイン同期(sync)入力のオン/オフ |

## ウィンドウ操作

| キー | 操作 |
|------|------|
| `Alt+t` | 新規ウィンドウ作成 |
| `Alt+n` | 次のウィンドウへ |
| `Alt+p` | 前のウィンドウへ |
| `Alt+q` | ウィンドウを閉じる |
| `Ctrl+t Space` | レイアウト変更 |

## コピーモード（vi風）

| キー | 操作 |
|------|------|
| `v` | 選択開始 |
| `y` | コピー（クリップボードへ） |
| `Enter` | コピーして終了 |
| `ESC` | 終了 |

## ポップアップ (tmux 3.2+)

| キー | 操作 |
|------|------|
| `Alt+g` | ポップアップシェル |
| `Alt+G` | lazygit (またはgit status) |

## プレフィックスキー操作 (`Ctrl+t` + キー)

プレフィックスキー `Ctrl+t` を押してから、続けてキーを押す操作。

### セッション・ウィンドウ管理

| キー | 操作 |
|------|------|
| `d` | セッションからデタッチ |
| `s` | セッション一覧を表示・選択 |
| `w` | ウィンドウ一覧を表示・選択 |
| `$` | セッション名を変更 |
| `,` | ウィンドウ名を変更 |
| `&` | 現在のウィンドウを終了（確認あり） |

### ペイン操作

| キー | 操作 |
|------|------|
| `z` | ペインをズーム（最大化/元に戻す） |
| `!` | ペインを新しいウィンドウに移動 |
| `x` | ペインを終了（確認あり） |
| `{` | ペインを前に移動 |
| `}` | ペインを後ろに移動 |
| `q` | ペイン番号を表示 |
| `o` | 次のペインに移動 |
| `Space` | レイアウトを切り替え |

### コピーモード・コマンド

| キー | 操作 |
|------|------|
| `[` | コピーモードに入る |
| `]` | バッファを貼り付け |
| `:` | コマンドモードに入る |
| `?` | キーバインド一覧を表示 |

### その他

| キー | 操作 |
|------|------|
| `r` | 設定ファイル再読み込み |
| `Ctrl+t` | 実際に `Ctrl+t` を入力（ネストしたtmux用） |
| `t` | 時計を表示 |

## インストール済みプラグイン

| プラグイン | 機能 |
|-----------|------|
| tpm | プラグインマネージャー |
| tmux-sensible | 便利なデフォルト設定 |
| tmux-yank | システムクリップボードへのコピー |
| tmux-resurrect | セッション保存・復元 |
| tmux-cpu | CPU使用率表示 |
| tmux-battery | バッテリー状態表示 |
| tmux-net-speed | ネットワーク速度表示 |
| tmux-logging | ログ記録 |
| tmux-copycat | 正規表現検索 |
| tmux-sidebar | サイドバー表示 |
| tmux-sessionist | セッション管理 |

## ステータスバー

- **左側**: セッション名、ウィンドウ番号、ペイン番号
- **右側**: ネットワーク速度、CPU使用率、日時
- **位置**: 上部
