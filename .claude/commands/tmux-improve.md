# tmux 改善スキル

tmux設定の改善を行うためのワークフロー。

## 概要

このスキルは以下のタスクをサポートします:
- 新しい改善アイデアのブレインストーミング
- アイデアの文書化
- 選択したアイデアの実装
- ドキュメントの更新

## 関連ファイル

- `dotfiles/tmux.conf` - メインの設定ファイル
- `dotfiles/docs/tmux-improvements.md` - 改善アイデア一覧 (23項目)
- `dotfiles/docs/tmux-usage.md` - 操作方法ドキュメント

## ワークフロー

### 1. 新しいアイデアを追加する場合

ユーザーが新しい改善アイデアを求めた場合:

1. 既存のアイデア一覧 (`docs/tmux-improvements.md`) を確認
2. 重複しない新しいアイデアを提案
3. ユーザーの承認後、`docs/tmux-improvements.md` に追記
4. 実装優先度まとめ表にも追加

### 2. アイデアを実装する場合

ユーザーが特定のアイデア番号を指定した場合 (例: "アイデア5を実装して"):

1. `docs/tmux-improvements.md` から該当アイデアを確認
2. `tmux.conf` に設定を追加
3. キーバインドがある場合は `docs/tmux-usage.md` を更新
4. `docs/tmux-improvements.md` の実装優先度まとめ表に ✅ を追加

### 3. 実装状況を確認する場合

1. `docs/tmux-improvements.md` の実装優先度まとめ表を参照
2. ✅ マークがついているものが実装済み

## コマンド例

```
# 新しいアイデアを考えて
/tmux-improve idea

# アイデア5を実装して
/tmux-improve implement 5

# 実装状況を確認
/tmux-improve status

# カテゴリ別に表示
/tmux-improve list navigation
```

## 注意事項

- tmux 3.2+ が必要な機能: #7, #14 (ポップアップ関連)
- 外部依存がある機能: #6, #12 (fzf), #9 (vim-tmux-navigator)
- シェル設定も必要な機能: #11 (コマンド完了通知)
